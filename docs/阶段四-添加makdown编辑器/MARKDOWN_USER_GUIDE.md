# Markdown 编辑器用户手册

> 本手册带你走完一次完整流程：主页模板 → 新建 → 实时预览 → 标签 → 搜索 → 双链 → 导出。

## 1. 进入 Markdown 工作区

1. 登录后，点击左上角汉堡菜单（☰）。
2. 选择 **Markdown**，进入 `/markdown` 工作区。
3. 主页与富文本「Docs」同构：顶部是「新建文档」分类模板，下方是「我的文档」网格与搜索框。

## 2. 新建文档

1. 点击 **New document**，在「Choose a Markdown template」弹窗中选择一个模板（空白、商务、个人、教育、创意共五类七个）。
2. 输入文档名（可留空，默认「Untitled Document」），点击 **Create**。
3. 进入 `/markdown/:id`，初始内容来自模板。

## 3. 编辑与实时预览

- 默认左侧为源码（CodeMirror）、右侧为预览，约 50/50。
- 在左侧输入 Markdown（标题 `#`、列表 `-`、表格、代码块、任务列表等），右侧 200ms 内同步渲染。
- 顶部工具栏可插入标题、加粗、斜体、代码、引用、列表、任务、链接、双链与表格。
- 快捷键：`Ctrl/Cmd+S` 立即保存，`Ctrl/Cmd+B` 加粗，`Ctrl/Cmd+I` 斜体。

## 4. 布局切换

点击编辑器上方的 **Source / Split / Preview** 在三种布局间切换；窄屏下 Split 自动回退为单栏。

## 5. 自动保存与冲突

- 停止输入 800ms 后自动保存，状态栏显示 `Saved`；有未保存改动显示 `Unsaved changes`。
- 刷新页面内容不丢；离线改动保留在本浏览器，恢复网络后自动重试。
- 若两个窗口同时编辑，会弹出 **Save conflict**，可选择「Load latest」或「Keep mine and overwrite」。

## 6. 标签

- 在编辑器顶部的 **Add tag** 输入框键入标签名并按 Enter 添加；点击标签旁的 ✕ 删除。
- 主页可按标签筛选，并显示每个标签的文档计数。

## 7. 搜索

- 主页搜索框支持中文/英文，覆盖标题、正文与标签，180ms 防抖后返回结果；命中词高亮并显示摘要。
- 只搜索你自己的 Markdown 文档；按 `Escape` 清空。

## 8. 双链与反链

- 在源码中输入 `[[标题]]` 创建双链；`[[标题|显示文字]]` 可自定义显示文字。
- 已解析的双链在预览中可点击跳转；未知双链显示「Find …」入口。
- 编辑器右侧的链接面板显示本文档的出链与引用本文档的反链，可点击跳转。

## 9. 导出

1. 点击编辑器上方的 **Export ▾** 按钮，展开导出菜单。
2. 选择格式：**Markdown (.md)**、**HTML (.html)**、**PDF (.pdf)**、**Word (.docx)**。
3. 文件以下载方式保存，文件名取自文档标题（自动去除非法字符）。
4. 导出始终使用编辑器里的最新内容（包括尚未自动保存的改动）。
5. 说明：PDF 由浏览器前端生成，大文档较慢；DOCX 的表格降级为纯文本、图片仅保留替代文字。

## 10. 权限说明

P0 阶段 Markdown 文档为 **仅所有者可见**：没有 Share / Comments / History 按钮，他人无法访问你的 Markdown 页面或接口。
